# Root Cause Analysis — documentation drift vs actual public surface (v0.3.0)

> **File:** `docs/root_cause/NEW-14_doc_drift_vs_public_surface.md` · **Date:** 2026-08-05 · **ID:** NEW-14

## Issue Summary
Several docs describe an API surface that differs from the shipped v0.3.0 code.
Full catalogue from the QA Phase 9 audit:

- **Phantom artifact filename** — `PROJECT_KNOWLEDGE_BASE.md:364,516`,
  `IMPLEMENTATION_ROADMAP.md:136,318,395`, `AUDIT_REPORT.md:44,141` claim an
  `evaluation_report.json` artifact; storage emits `evaluation.json` (canonical
  JSON report is `pipeline.json`). No such filename exists in code.
- **CLI undercount** — `PUBLIC_API_AUDIT.md:62` (4 commands), `API_Contracts.md:46-48`
  (2), `IMPLEMENTATION_ROADMAP.md:106` (2), and the entire `docs/guides/cli.md`
  (191 lines, only `run`/`info`) describe far fewer than the real 12 commands.
- **Simple API count** — `API_Contracts.md:14` and `IMPLEMENTATION_ROADMAP.md:82`
  say "12 functions"; the module exports 23 (`PUBLIC_API_AUDIT.md:40` correctly).
- **Phantom params/attributes/returns** that raise `TypeError`/`AttributeError`
  if used: `fill_value=` on `clean` (examples.md:130,156; index.md:156;
  getting-started.md:204; simple-api.md:107; incremental.md:21,64; advanced-api.md:204;
  API_Contracts.md:27); `DatasetProfile.numeric_columns/.categorical_columns/.preview`
  (simple-api.md:47,48,134-136; examples.md:43,100-101); `CleanResult.shape`
  (simple-api.md:68,209; examples.md:127,131,135); `WorkflowState.target_confidence`
  (incremental.md:166; advanced-api.md:151 — real field `target_detection_confidence`);
  `EvaluationMetrics.get()` (examples.md:68-69); `json.dump(metrics)`
  (examples.md:336); "all stage methods return self" chaining (advanced-api.md:178-196;
  incremental.md:129-135); `simple.report` typed as dict (PUBLIC_API_AUDIT.md:28 — real: `str`).
- **Stage/artifact miscounts** — `rest_api_removal_report.md:90` "17-stage pipeline",
  "3 artifacts" (real: 11 stages; 17-file suite written when a model exists).

## Root Cause
Documentation is maintained as prose independent of the code; nothing enforces
that doc examples/API listings stay in sync with `simple.py`, `sdk.py`, storage
artifacts, and the CLI registry. Each doc was written at a different time and
edited piecemeal (REST-era files retained post-removal), so numeric claims
(counts, filenames) and API signatures silently rotted. NEW-01..NEW-08 fixed code
defects; none touched the doc layer, so the drift accumulated.

## Affected Components
- `docs/guides/cli.md`, `docs/guides/simple-api.md`, `docs/guides/incremental.md`,
  `docs/guides/advanced-api.md`, `docs/examples.md`, `docs/index.md`,
  `docs/getting-started.md`
- `project_docs/PROJECT_KNOWLEDGE_BASE.md`, `IMPLEMENTATION_ROADMAP.md`,
  `PUBLIC_API_AUDIT.md`, `API_Contracts.md`, `AUDIT_REPORT.md`,
  `rest_api_removal_report.md`

## Affected APIs
- Doc-only. Code surface is correct: 23 simple functions, 12 CLI commands,
  `evaluation.json`/`pipeline.json` artifacts.

## Affected SDK Functions
- none (docs misstate `DatasetProfile`, `CleanResult`, `WorkflowState`, `EvaluationMetrics`)

## Affected CLI
- none (docs misstate command count; no phantom commands claimed)

## Fix Applied
- **Resolved in the v0.3.0 release pass (2026-08-05).** Applied the recommended
  fix (choke point item 1) in place:
  - Phantom `evaluation_report.json` corrected to `evaluation.json` in
    `PROJECT_KNOWLEDGE_BASE.md:364,516`, `IMPLEMENTATION_ROADMAP.md:136,318,395`,
    and `AUDIT_REPORT.md:44,141` (single source of truth: `services/storage.py`
    constants; canonical JSON reports are `evaluation.json` and `pipeline.json`).
  - CLI undercount corrected: `docs/guides/cli.md` now lists all **13** commands
    (was `run`/`info` only) with `evaluate`/`compare` sections added;
    `PUBLIC_API_AUDIT.md:62` and `IMPLEMENTATION_ROADMAP.md:82,106` updated.
  - Simple API count corrected to 23 (`IMPLEMENTATION_ROADMAP.md:82`).
  - Phantom params/attributes removed from `docs/guides/simple-api.md`
    (`fill_value=` on `clean`, `DatasetProfile.numeric_columns`/
    `.categorical_columns`/`.preview`, `CleanResult.shape`); `PUBLIC_API_AUDIT.md:28`
    now types `simple.report` as `str`.
  - Regression suite: `tests/test_regressions_v030.py` (NEW-09..NEW-13) added;
    the doc-guard tests (choke point item 3) remain deferred to a future pass.

### Recommended Fix (choke point)
1. Correct the four numeric/filename claims above in place (single source of
   truth: read from code).
2. Replace prose API listings with autogenerated references: CLI section of
   `docs/guides/cli.md` from `phronesisml --help` output; simple-API listing from
   `__all__`; artifact filenames from `services/storage.py` constants.
3. Delete REST-era sections (e.g. `AUDIT_REPORT.md`, `rest_api_removal_report.md`)
   or mark them historical.

## Regression Test Added
- None yet. Required: a doc-guard test that (a) asserts the CLI command set in
  `docs/guides/cli.md` matches `typer` commands at runtime, (b) asserts doc-cited
  artifact filenames exist in the storage writer constants, and (c) runs the
  doc examples' attribute accesses against real dataclasses. See Phase 11.

## Future Prevention
- A CI doc-sync job that renders `--help` and the dataclass field list into the
  guides, failing on drift. Add doc examples to the example-testing harness so
  every snippet executes.
